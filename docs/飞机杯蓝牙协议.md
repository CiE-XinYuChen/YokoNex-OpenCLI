# YSKJ_TOY_BLE 通信协议 — 飞机杯 / 跳蛋设备

> 协议版本：V1.1  
> 适用设备：飞机杯、跳蛋及同类多马达玩具  
> 协议名称：`YSKJ_TOY_BLE`

---

## 1. 术语定义

| 术语 | 说明 |
|------|------|
| 主机 | 手机（App 端） |
| 从机 | BLE 设备（飞机杯/跳蛋） |
| 字节序 | 多字节数据默认最高字节在前，最低字节在后（大端序） |
| 马达 A/B/C | 设备内最多三路独立马达 |

---

## 2. BLE 服务与特征值

### 服务过滤

扫描时过滤 Primary Service UUID：

```
0000ff40-0000-1000-8000-00805f9b34fb
```

### GATT 结构

| 项目 | UUID | 属性 |
|------|------|------|
| Primary Service | `FF40` | — |
| Write Characteristic | `FF41` | `WRITE_WITHOUT_RESPONSE \| DYNAMIC` |
| Notify Characteristic | `FF42` | `NOTIFY` |

**通信方向：**
- 主机 → 从机：写入 `FF41`
- 从机 → 主机：通过 `FF42` 主动上报；主机需订阅 Notify

---

## 3. 校验和算法

所有数据包最后一字节为**累加和校验**，计算方式：

```
checksum = (byte1 + byte2 + ... + byteN-1) & 0xFF
```

---

## 4. 命令总览

| 命令字 | 方向 | 功能 |
|--------|------|------|
| `0x10` | 双向 | 设备信息查询 / 应答 |
| `0x11` | 主机 → 从机 | 固定模式控制 |
| `0x12` | 主机 → 从机 | 速率控制（实时） |
| `0x13` | 从机 → 主机 | 电池电量上报 |

---

## 5. 协议详述

### 5.1 设备信息查询（0x10）

连接建立后，主机主动下发此命令获取设备信息，以决定 UI 显示和操控方式。

#### 请求（主机 → 从机）

| 字节 | 字段 | 值 |
|------|------|----|
| 1 | 包头 | `0x35` |
| 2 | 命令字 | `0x10` |
| 3 | 校验和 | `(0x35 + 0x10) & 0xFF` = `0x45` |

#### 应答（从机 → 主机）

| 字节 | 字段 | 说明 |
|------|------|------|
| 1 | 包头 | `0x35` |
| 2 | 命令字 | `0x10` |
| 3 | 产品型号 ID | 同款产品唯一 ID，范围 1–255 |
| 4 | 产品版本号 | 默认 1，产品迭代时递增，最大 255 |
| 5 | A 马达模式数量 | 无 A 马达填 `0`；有则填该马达固定模式数量 N |
| 6 | B 马达模式数量 | 无 B 马达填 `0`；有则填该马达固定模式数量 N |
| 7 | C 马达模式数量 | 无 C 马达填 `0`；有则填该马达固定模式数量 N |
| 8 | 预留 | `0x00` |
| 9 | 预留 | `0x00` |
| 10 | 校验和 | 累加和校验 |

**示例（单马达设备，8 种固定模式）：**

```
35 10 01 01 08 00 00 00 00 [checksum]
```

---

### 5.2 固定模式控制（0x11）

控制指定马达以某一固定模式运行。

#### 请求（主机 → 从机，无需应答）

| 字节 | 字段 | 值 |
|------|------|----|
| 1 | 包头 | `0x35` |
| 2 | 命令字 | `0x11` |
| 3 | 马达选择 | 见下表 |
| 4 | 模式选择 | `0`：关闭；`1–N`：选择固定模式编号 |
| 5 | 校验和 | 累加和校验 |

**马达选择位掩码：**

| 值 | 含义 |
|----|------|
| `0x01` | A 马达 |
| `0x02` | B 马达 |
| `0x03` | AB 马达（同时控制） |
| `0x04` | C 马达 |
| `0x07` | ABC 马达（同时控制） |

> N 的值来自设备信息查询（0x10）应答中对应马达的模式数量字段。

**示例（A 马达选择模式 3）：**

```
35 11 01 03 [checksum]
```

**示例（关闭所有马达）：**

```
35 11 07 00 [checksum]
```

---

### 5.3 速率控制（0x12）

适用于**手势模式、语音/音乐模式、自定义模式**等需要实时下发力度的场景。

#### 请求（主机 → 从机，无需应答）

| 字节 | 字段 | 值 |
|------|------|----|
| 1 | 包头 | `0x35` |
| 2 | 命令字 | `0x12` |
| 3 | 马达 A 力度 | `0`：关闭；`1–20`：力度等级 |
| 4 | 马达 B 力度 | `0`：关闭；`1–20`：力度等级 |
| 5 | 马达 C 力度 | `0`：关闭；`1–20`：力度等级 |
| 6 | 校验和 | 累加和校验 |

> **注意**：仅在数据发生变化时才需要下发，避免无效通信。

**示例（A 马达力度 10，B/C 马达关闭）：**

```
35 12 0A 00 00 [checksum]
```

---

### 5.4 电池电量上报（0x13）

从机主动上报，主机无需应答。

#### 上报（从机 → 主机）

| 字节 | 字段 | 值 |
|------|------|----|
| 1 | 包头 | `0x35` |
| 2 | 命令字 | `0x13` |
| 3 | 上报类型 | `0x01`：电池电量 |
| 4 | 电量 | `0–100`，对应 0%–100% |
| 5 | 校验和 | 累加和校验 |

---

## 6. 接入流程

```
1. 扫描 BLE 设备，过滤 Service UUID = 0000ff40-0000-1000-8000-00805f9b34fb
2. 连接设备
3. 订阅 FF42 的 Notify
4. 发送设备信息查询命令（0x10），获取产品型号和马达模式数量
5. 根据应答内容构建 UI 控件
6. 下发固定模式控制（0x11）或实时速率控制（0x12）
7. 监听 FF42 接收电量上报（0x13）
```

---

## 7. 校验和计算示例

以固定模式控制包 `35 11 01 03` 为例：

```
checksum = (0x35 + 0x11 + 0x01 + 0x03) & 0xFF
         = 0x4A
```

完整包：`35 11 01 03 4A`
