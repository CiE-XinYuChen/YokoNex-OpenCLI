# YSKJ_EMS_BLE 通信协议 — 二代电击器

> 协议版本：V1.6  
> 适用设备：双通道 EMS 电击器（二代）  
> 协议名称：`YSKJ_EMS_BLE`

---

## 1. 术语定义

| 术语 | 说明 |
|------|------|
| 主机 | 手机（App 端） |
| 从机 | BLE 设备（二代电击器） |
| EMS | Electrical Muscle Stimulation，肌肉电刺激 |
| 字节序 | 多字节数据默认最高字节在前，最低字节在后（大端序） |
| A 通道 / B 通道 | 设备内两路独立 EMS 通道 |

---

## 2. BLE 服务与特征值

### 服务过滤

扫描时过滤 Primary Service UUID：

```
0000ff30-0000-1000-8000-00805f9b34fb
```

### GATT 结构

| 项目 | UUID | 属性 |
|------|------|------|
| Primary Service | `FF30` | — |
| Write Characteristic | `FF31` | `WRITE_WITHOUT_RESPONSE \| DYNAMIC` |
| Notify Characteristic | `FF32` | `NOTIFY` |

**通信方向：**
- 主机 → 从机：写入 `FF31`
- 从机 → 主机：通过 `FF32` 主动上报；主机需订阅 Notify

---

## 3. 设备基本参数

该设备含 **A 通道**和 **B 通道**两路独立 EMS 通道，每路包含以下参数：

| 参数 | 说明 |
|------|------|
| 通道开关状态 | 当前通道是否输出 |
| 通道 EMS 强度 | 范围 `0x01`–`0x114`，共 276 等级 |
| 通道模式 | 16 种固定模式（`0x01`–`0x10`）+ 1 种自定义模式（`0x11`） |
| 通道连接状态 | 电极片是否接入并贴合人体 |

**固定模式**（16 种）已固化在设备内，直接选择编号使用。  
**自定义模式** `0x11`：仅使用强度和频率两个参数，参数保存在手机端，最快 100ms 下发一次。

---

## 4. 校验和算法

所有数据包最后一字节为**累加和校验**：

```
checksum = (byte1 + byte2 + ... + byteN-1) & 0xFF
```

---

## 5. 命令总览

| 命令字 | 方向 | 功能 |
|--------|------|------|
| `0x11` | 主机 → 从机 | 通道控制（EMS 输出） |
| `0x12` | 主机 → 从机 | 马达控制 |
| `0x13` | 主机 → 从机 | 计步功能控制 |
| `0x14` | 主机 → 从机 | 角度传感器控制 |
| `0x71` | 双向 | 查询命令 / 状态应答 / 异常上报 |

## 6. 协议详述

### 6.1 通道控制（0x11）

控制 EMS 通道的开关、强度、模式和频率。

#### 请求（主机 → 从机）

| 字节 | 字段 | 值 |
|------|------|----|
| 1 | 包头 | `0x35` |
| 2 | 命令字 | `0x11` |
| 3 | 通道号 | `0x01`：A 通道；`0x02`：B 通道；`0x03`：AB 通道同步 |
| 4 | 通道开启状态 | `0x00`：关闭；`0x01`：开启 |
| 5–6 | 通道强度 | 仅通道开启时有效；`0x0001`–`0x0114`（276 等级） |
| 7 | 通道模式 | 仅通道开启时有效；固定模式 `0x01`–`0x10`；自定义模式 `0x11` |
| 8 | 通道频率 | 仅自定义模式有效，固定模式填 `0x00`；`0x01`–`0x64`（1–100 Hz） |
| 9 | 脉冲时间 | 仅自定义模式有效，固定模式填 `0x00`；`0x00`–`0x64`（0–100 µs） |
| 10 | 校验和 | 累加和校验 |

**注意事项：**
1. 调节强度时，通道模式也须同时下发；调节模式时，强度也须同时下发。
2. 通道关闭命令时，从机自动忽略强度及模式字段。
3. AB 通道同步时，通道号使用 `0x03`，无需分别下发 A、B。

**示例（A 通道开启，强度 50，固定模式 3）：**

```
35 11 01 01 00 32 03 00 00 [checksum]
checksum = (0x35+0x11+0x01+0x01+0x00+0x32+0x03+0x00+0x00) & 0xFF = 0x7D
完整包：35 11 01 01 00 32 03 00 00 7D
```

**示例（AB 通道关闭）：**

```
35 11 03 00 00 00 00 00 00 [checksum]
```

**示例（A 通道开启，自定义模式，强度 30，频率 20Hz，脉冲时间 50µs）：**

```
35 11 01 01 00 1E 11 14 32 [checksum]
```

---

### 6.2 马达控制（0x12）

控制设备内置震动马达（用于提示反馈等）。

#### 请求（主机 → 从机）

| 字节 | 字段 | 值 |
|------|------|----|
| 1 | 包头 | `0x35` |
| 2 | 命令字 | `0x12` |
| 3 | 状态 | `0x00`：关闭；`0x01`：开启；`0x11`：预设频率 1；`0x12`：预设频率 2；`0x13`：预设频率 3 |
| 4 | 校验和 | 累加和校验 |

**注意：**
- 设备开机后马达会自动震动 1 秒。
- 陀螺仪应用开启时，马达震动会影响陀螺仪数据，此时不应开启马达。

---

### 6.3 计步功能（0x13）

控制设备内置计步传感器。

#### 请求（主机 → 从机）

| 字节 | 字段 | 值 |
|------|------|----|
| 1 | 包头 | `0x35` |
| 2 | 命令字 | `0x13` |
| 3 | 状态 | `0x00`：关闭；`0x01`：开启；`0x02`：清零；`0x03`：暂停；`0x04`：恢复 |
| 4 | 校验和 | 累加和校验 |

> 计步开启后，从 0 开始计步并实时上报，也可通过查询命令（`0x71 0x05`）主动获取。

---

### 6.4 角度功能（0x14）

控制设备内置陀螺仪/重力传感器。

#### 请求（主机 → 从机）

| 字节 | 字段 | 值 |
|------|------|----|
| 1 | 包头 | `0x35` |
| 2 | 命令字 | `0x14` |
| 3 | 状态 | `0x00`：关闭；`0x01`：开启 |
| 4 | 校验和 | 累加和校验 |

> 角度开启后，实时上报传感器原始值（六轴数据），需 App 端自行计算角度。也可通过查询命令（`0x71 0x06`）主动获取。

---

### 6.5 查询命令（0x71）

主机主动查询，或从机状态变更时主动上发。

#### 查询请求（主机 → 从机）

| 字节 | 字段 | 值 |
|------|------|----|
| 1 | 包头 | `0x35` |
| 2 | 命令字 | `0x71` |
| 3 | 查询类型 | 见下表 |
| 4 | 校验和 | 累加和校验 |

| 查询类型 | 说明 |
|----------|------|
| `0x01` | 通道 A 状态 |
| `0x02` | 通道 B 状态 |
| `0x03` | 马达状态 |
| `0x04` | 电池电量 |
| `0x05` | 计步数据 |
| `0x06` | 角度数据 |

---

## 7. EMS 强度等级参考

| 等级范围 | 十六进制 | 说明 |
|----------|----------|------|
| 1–100 | `0x01`–`0x64` | 低强度区间 |
| 101–200 | `0x65`–`0xC8` | 中强度区间 |
| 201–276 | `0xC9`–`0x114` | 高强度区间 |

> **安全提示**：请从低等级开始使用，逐步调节，严禁在高强度下突然开启通道。遵循设备官方文档安全使用设备。

---

## 8. 接入流程

```
1. 扫描 BLE 设备，过滤 Service UUID = 0000ff30-0000-1000-8000-00805f9b34fb
2. 连接设备
3. 订阅 FF32 的 Notify
4. 查询通道 A/B 当前状态（0x71 0x01 / 0x71 0x02），同步 UI
5. 查询电池电量（0x71 0x04）
6. 下发通道控制命令（0x11）控制 EMS 输出
7. 如需计步或角度功能，分别下发 0x13 / 0x14 开启
8. 监听 FF32 Notify 接收从机主动上报的所有状态变更和异常
```

## 9. 自定义模式使用示例

以 A 通道开启自定义模式、频率 10Hz、脉冲时间 20µs、强度 100 为例：

```
字节:  35   11   01   01  00  64   11   0A   14   [cs]
说明: 头  cmd  A通道  开  强度=100  自定义  10Hz  20µs  校验
checksum = (0x35+0x11+0x01+0x01+0x00+0x64+0x11+0x0A+0x14) & 0xFF = 0xDB
完整包：35 11 01 01 00 64 11 0A 14 DB
```

每次参数变化时重新下发，最快间隔 **100ms**。
